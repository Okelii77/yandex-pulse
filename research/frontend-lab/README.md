# Browser profiling (offline)
Real Chrome on a local HTTP fixture of all catalog checks, 214 synthetic history points per check. 10 measured cold navigations per desktop/mobile after one warmup; CDP metrics and range interactions. Network cache disabled and external requests blocked. No production credentials or requests. Metrics include browser startup-independent page-ready time (CDP polling adds up to 100ms), Navigation Timing, resources and JS transfer bytes, JS heap, graph interaction-to-two-animation-frames, script and layout deltas. Graph frame timing is not pure rendering CPU. No results are claimed until workflow succeeds.
