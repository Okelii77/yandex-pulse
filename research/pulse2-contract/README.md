# Contracts for Pulse 2.0
Local-only ETag/delta client, coalesced polling, hidden-tab and degraded intervals, stale handling, mocked workflow dispatch transport. Status/history revisions are separate, delta tag differs from full representation. Production cross-origin requests need explicit Access-Control-Allow-Headers: If-None-Match and Access-Control-Expose-Headers: ETag; same-origin assets avoid preflights. No existing site code changed. The dispatch target file does not exist on main; workflow_dispatch requires a workflow on the default branch. Do not create or dispatch it without approval. A dedicated repository-scoped Actions:write fine-grained credential or GitHub App can dispatch; note that Actions:write is repository-wide, not workflow-specific. Worker must fix workflow/ref in code. Keep production OIDC audience/ref binding and separate lease fencing. A 204 is accepted, not proof of runner or publication. On uncertain dispatch, wait for lease expiry and never blindly repeat immediately. Source https://docs.github.com/en/rest/actions/workflows and https://docs.github.com/en/actions/reference/workflows-and-actions/events-that-trigger-workflows. Quota model uses an explicit cold scan assumption, not actual D1 row usage.
