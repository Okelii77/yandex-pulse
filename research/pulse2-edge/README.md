# Local Cloudflare runtime lab
No deployed Worker or remote D1, no Cloudflare credentials. Miniflare v4 runs workerd with a fresh local DB per variant. JS, compiled TS, full Rust workers-rs D1 binding, hybrid TS + bulk Rust/Wasm compute use same 4096 integer rows and exact output. 100 warm requests, first request after DB seed, runtime startup, process-level workerd CPU ticks and VmHWM. Process totals include D1 emulator and runtime, not per-isolate cloud CPU, billing, memory or true network cold start. JS and TS should be equivalent after compilation. Local D1 materialization/rollback experiment uses 48,960 rows; local meta may not reflect cloud quota accounting. The D1 scheduler invokes only an injected mock callback and validates fencing/lease expiry. It does not dispatch actual Actions or change cron. No deployed resources. Actual cloud CPU/billing tests blocked until plan/quota safety verified.
